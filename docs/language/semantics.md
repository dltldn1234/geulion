# 실행 의미론

**상태: Specified** — 이 문서는 문법을 만족하는 v0.1 프로그램의 이름 해석, 평가 및 제어 흐름을 정의합니다. JavaScript 코드 생성이나 runtime이 구현되었다는 의미는 아닙니다.

## 프로그램과 함수

- 한 `.geul` 파일은 하나의 실행 프로그램입니다. 파일 최상위에는 함수 선언만 올 수 있고, 최상위 변수나 실행 문장은 허용하지 않습니다.
- 프로그램에는 정확히 하나의 `함수 시작() -> 없음`이 있어야 합니다. 이 함수가 없거나, 매개변수가 있거나, 반환 타입이 `없음`이 아니면 의미 오류입니다.
- 함수 선언은 파일 어디에 있어도 서로의 이름과 시그니처를 참조할 수 있습니다. 타입 검사는 모든 함수 시그니처를 먼저 수집한 뒤 함수 본문을 검사합니다. 재귀와 상호 재귀를 허용합니다.
- 함수 이름은 하나의 시그니처만 가집니다. 오버로딩, 기본 인자, 중첩 함수, 함수 값, 함수 이름을 인자로 전달하는 동작은 v0.1에서 지원하지 않습니다.
- 프로그램 실행은 `시작` 본문을 정확히 한 번 호출하는 것으로 시작합니다. 정상 반환 시 프로그램은 정상 종료합니다. 함수 선언은 최상위 초기화 동작을 하지 않습니다.
- v0.1에는 import/export, 여러 파일 모듈, 전역 변수/상수, library-only compilation이 없습니다.

## 이름과 스코프

- 선언된 함수와 세 prelude 함수(`출력`, `정수로`, `실수로`)는 프로그램 함수 이름 공간에 있습니다. 같은 NFC 이름의 함수 중복 선언이나 prelude 재정의는 `GE2002`입니다.
- 매개변수와 `상수`/`변수`는 값 이름 공간의 lexical binding입니다. 같은 block 안 중복 선언은 `GE2002`입니다. 자식 block은 바깥 값 이름을 가릴 수 있고, 가장 안쪽 선언이 선택됩니다.
- 함수 및 prelude 이름은 값 이름과 충돌할 수 없습니다. 어느 block에서도 함수 이름과 같은 매개변수/변수를 선언하면 `GE2002`입니다. 따라서 `출력` 변수가 `출력(...)` 함수 호출을 가리는 일이 없습니다.
- 함수 본문 block은 매개변수 scope를 공유합니다. 매개변수와 본문 최상위 지역 변수의 이름은 중복될 수 없습니다. `{...}`, `만약`/`아니면` branch block, `동안` body는 각각 새 scope입니다.
- 지역 선언은 초기화 식이 끝난 뒤부터 현재 block 끝까지 보입니다. 자기 초기화는 새 binding을 읽지 않습니다. 같은 이름의 바깥 binding이 있다면 초기화 식은 바깥 binding을 읽습니다.
- 함수 호출은 함수 이름과 시그니처로 정적으로 해석합니다. 식별자를 값으로 쓸 때는 선언된 지역 값이어야 합니다. 미해결 값/함수 호출은 `GE2001`입니다. 선언된 함수를 호출하지 않고 식별자 값으로 쓰면 `GE3002`입니다.
- `시작`은 일반적인 식별자 토큰이지만 의미 단계에서 진입점 규칙을 적용합니다. `시작`이라는 함수 외에 다른 entrypoint 표기는 없습니다.

## 값, 변경 및 전달

- 원시값, 문자열, 목록, 사전, 선택값은 모두 **값 의미론**을 가집니다. 대입과 함수 인자 전달은 값의 의미상 복사입니다. 구현은 불변 값의 storage를 내부적으로 공유할 수 있지만 alias를 관찰할 수 없어야 합니다.
- `상수`는 binding을 다시 대입할 수 없게 합니다. `변수`는 같은 정적 타입 값으로 다시 대입할 수 있습니다. 이는 객체의 내부 변경 가능성을 뜻하지 않습니다.
- `목록`과 `사전`은 불변입니다. 원소 대입/추가/삭제 메서드는 문법이나 prelude에 없습니다. 목록/사전 전체를 `변수` binding에 새 값으로 대입할 수 있습니다.
- 모든 함수 인자 평가는 왼쪽에서 오른쪽이며 호출마다 새 매개변수와 지역 binding을 가진 call frame을 만듭니다.
- `문자열` 연결 결과는 왼쪽 문자열 뒤에 오른쪽 문자열의 Unicode scalar 순서를 그대로 붙입니다. 정규화, locale 변환, 자동 문자열화는 하지 않습니다.

## 평가 순서와 연산

일반 이항 연산은 왼쪽 피연산자를 먼저, 오른쪽 피연산자를 다음에 평가합니다. 함수 인자, 목록 원소, 사전 항목도 소스 순서로 평가합니다. 대입은 오른쪽 식을 완전히 평가한 다음 대상 `변수` binding을 교체합니다.

- `그리고`, `또는`은 단락 평가합니다. 왼쪽 값만으로 결과가 정해지면 오른쪽 식을 평가하지 않습니다.
- `A ?? B`는 `A`를 먼저 평가합니다. `A`가 `일부(x)`이면 `x`를 반환하고 `B`를 평가하지 않습니다. `A`가 `비어있음`이면 `B`를 평가합니다.
- 평가 순서와 오류는 연산자 우선순위/결합 방향과 독립적이며, 최적화 후에도 관찰 가능한 순서가 보존되어야 합니다.

## 정수 및 실수 연산

### 정수

`정수`는 범위 `−9,223,372,036,854,775,808`부터 `9,223,372,036,854,775,807`까지의 signed 64-bit 값입니다. JavaScript 백엔드는 `bigint`를 사용해야 하며, `Number`로 정수 계산을 해서는 안 됩니다.

- 정수 리터럴은 10진 magnitude를 임의 정밀도로 읽어 범위를 검사합니다. magnitude `2^63`은 바로 적용되는 단항 `-`와 하나의 signed literal로 취급해 `−2^63`으로 허용합니다. 이 검사에서 괄호 식은 제거하지만 다른 연산은 제거하지 않습니다. 따라서 `-9223372036854775808` 및 `-(9223372036854775808)`은 허용하고, 양수형 `9223372036854775808`은 `GE3007`입니다. `-(-9223372036854775808)`은 유효한 런타임 단항 연산이며 실행 시 `GE4001`입니다.
- `+`, `-`, `*`, unary `-`는 정확한 수학 연산을 한 뒤 결과 범위를 확인합니다. 범위를 벗어나면 wraparound하지 않고 `GE4001`로 중단합니다.
- `/`는 0 방향으로 자르는 정수 나눗셈입니다. `%`의 나머지는 0이 아니면 피제수와 같은 부호를 가집니다.
- 0으로 나누거나 0으로 나머지를 구하면 `GE4002`입니다. `−2^63 / −1`도 결과가 범위를 벗어나므로 `GE4001`입니다.
- 리터럴 이외 계산이 범위를 벗어나면 runtime 진단입니다. 구현의 constant folding 여부가 프로그램의 허용 여부나 진단 결과를 바꾸면 안 됩니다.

### 실수

`실수` 연산은 IEEE 754 binary64 최근접 반올림(동률은 짝수)을 따릅니다. `+`, `-`, `*`, `/`가 허용됩니다. 실수 나눗셈의 0 제수는 trap이 아닙니다. IEEE 결과인 부호 있는 무한대 또는 `NaN`을 냅니다. `NaN` 비교는 IEEE 규칙을 따릅니다. 즉 `NaN == NaN`은 거짓, `NaN != NaN`은 참이고 순서 비교는 거짓입니다. `+0.0 == -0.0`은 참입니다.

실수 리터럴을 binary64로 변환할 때도 최근접-짝수 규칙을 사용합니다. 유한 소스 리터럴이 무한대로 넘치면 `GE3007` compile-time 오류입니다. underflow와 subnormal은 binary64 규칙대로 허용합니다. 실수에는 `%`를 사용할 수 없습니다.

## 비교, 동등성 및 컬렉션

- `<`, `<=`, `>`, `>=`는 `정수`끼리 또는 `실수`끼리만 허용합니다. 문자열 순서 비교는 정의하지 않습니다.
- `==`, `!=`는 같은 타입 값끼리만 허용합니다. 목록은 길이와 같은 위치 원소를 재귀 비교합니다. 사전은 key/value 집합을 비교하고 삽입 순서는 무시합니다. 선택값은 variant가 같을 때 payload를 비교합니다. 내부 실수 비교도 IEEE 규칙이므로 `NaN`을 포함한 컬렉션은 자기 자신과도 동등하지 않을 수 있습니다.
- 문자열 동등 비교는 정규화 없이 Unicode scalar 값 순서열을 비교합니다. 식별자 정규화 규칙은 문자열 값에 적용하지 않습니다.
- 목록 인덱스는 0부터 시작합니다. 음수, 길이 이상, 또는 사전에 없는 키는 runtime 실패가 아니라 `비어있음`을 반환합니다. 잘못된 index 타입은 `GE3002`입니다.
- 사전 리터럴 중복 키는 source string value가 코드 포인트 단위로 같으면 `GE3008`입니다. 서로 다르게 정규화되는 문자열은 서로 다른 key입니다.

## 조건, 반복 및 반환

- `만약`과 `동안` 조건은 `불리언`만 받습니다. 0, 빈 문자열, Unit 등 다른 타입의 truthiness는 없습니다.
- `동안`은 조건식을 실행 전에 평가하고, 참일 때 body를 실행한 뒤 다시 조건을 평가합니다. `중단`은 가장 안쪽 반복문을 끝내고 `계속`은 가장 안쪽 반복문의 다음 조건 검사로 이동합니다. 반복문 밖의 두 문장은 `GE3004`입니다.
- `아니면`이 없는 조건문의 거짓 branch는 아무 동작도 하지 않습니다. `만약`은 값을 반환하는 식이 아닙니다.
- `반환 E`의 `E` 타입은 함수 반환 타입과 정확히 같아야 합니다. `반환` 단독은 반환 타입 `없음` 함수에서만 허용합니다. `없음` 함수는 끝에 도달해도 정상 반환합니다.
- `없음`이 아닌 함수는 모든 도달 가능한 경로에서 값을 반환해야 합니다. 양 branch가 모두 반환하는 `만약 ... 아니면 ...`은 경로를 종료합니다. `동안`은 최소 한 번 실행된다고 보장되지 않으므로 반복문만으로 반환 완전성을 충족하지 않습니다. 미충족은 `GE3005`입니다.
- `중단`/`계속`은 현재 가장 안쪽 `동안`의 범위에서만 유효합니다. `반환`은 현재 함수에서만 제어를 종료합니다.

## Prelude 관찰 의미

`출력(x)`는 `x`를 다음 canonical 문자열로 만들어 표준 출력에 UTF-8로 기록하고 U+000A 하나를 덧붙입니다. Locale, 운영체제 언어 및 지역 설정은 결과에 영향을 주지 않습니다.

| 값          | 표시                                                                                                                                                                                                  |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 정수        | 부호가 필요한 경우 `-`를 붙인 10진 숫자, grouping 없음                                                                                                                                                |
| 유한 실수   | binary64 값으로 되돌릴 수 있는 가장 짧은 10진수. ECMAScript [`Number::toString`](https://tc39.es/ecma262/#sec-number.prototype.tostring)의 표기를 따르고, 결과에 소수점/지수부가 없으면 `.0`을 덧붙임 |
| 특수 실수   | `NaN`, `Infinity`, `-Infinity`; 음의 영은 `-0.0`, 양의 영은 `0.0`                                                                                                                                     |
| 문자열      | 따옴표 없이 값 자체                                                                                                                                                                                   |
| 불리언/Unit | `참`, `거짓`, `없음`                                                                                                                                                                                  |
| 목록        | `[값, 값]` 형식으로 재귀 표시                                                                                                                                                                         |
| 사전        | `{"key": 값}` 형식. 키를 Unicode scalar 순서로 정렬하고 문자열 key는 JSON 호환 escape로 인용                                                                                                          |
| 선택        | `일부(값)` 또는 `비어있음`                                                                                                                                                                            |

사전 key의 canonical escape는 `"`, `\\`, `\b`, `\f`, `\n`, `\r`, `\t`를 해당 escape로 출력합니다. 그 외 U+0000..U+001F는 소문자 16진수 `\u00xx`로 escape하고, 나머지 Unicode scalar는 그대로 출력합니다. `/`와 비ASCII 문자는 escape하지 않으며 NFC도 적용하지 않습니다. 이 규칙은 사전 key 표시용이며 top-level 문자열 `출력`은 값을 그대로 씁니다.

JavaScript 백엔드는 `bigint` 출력 시 `n` 접미사를 붙이면 안 됩니다. `출력`은 canonical 문자열과 U+000A 하나를 기록하고 결과로 `없음` 값을 냅니다. 문자열 payload 안의 LF는 그대로 출력되므로 문자열을 포함한 출력이 여러 물리 줄을 만들 수 있습니다.

## Runtime 실패와 백엔드

runtime 실패는 예외를 포착하는 언어 기능이 아닙니다. 첫 runtime 오류를 진단한 뒤 현재 프로그램 실행을 중단합니다. v0.1에는 `try`/`catch`, 사용자 예외, defer/finally가 없습니다. runtime 오류를 출력만 하고 실행을 계속해서는 안 됩니다.

| 원인                                   | 진단     |
| -------------------------------------- | -------- |
| checked 정수 범위 초과                 | `GE4001` |
| 정수 나눗셈/나머지의 0 제수            | `GE4002` |
| `정수로`에서 비유한 값 또는 범위 밖 값 | `GE4003` |
| 표준 출력 실패                         | `GE4004` |

각 runtime 진단은 문제가 발생한 원본 식의 source span을 가리켜야 합니다. ECMAScript 구현은 정수 범위 검사, signed 64-bit 경계, 값 전달, 출력 문자열을 명시적으로 보장해야 하며 JavaScript의 기본 `Number` 정수 의미를 사용하지 않습니다. 다른 backend도 동일한 결과와 실패 지점을 보존해야 합니다.

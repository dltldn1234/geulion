# 타입 체계

**상태: Specified** — GEULION v0.1의 정적 타입 규칙입니다. 문서가 Specified라는 뜻이며 구현 상태는 아닙니다.

## 타입 집합

모든 타입은 정적이며 값은 실행 중 다른 타입으로 바뀌지 않습니다. v0.1에는 하위 타입, 사용자 정의 타입 선언, 사용자 정의 제네릭, 함수 값 타입이 없습니다.

| 타입      | 의미                                                                                                | JavaScript 백엔드 표현 계약                                              |
| --------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| `정수`    | 부호 있는 64비트 2의 보수 정수, 범위 `−2^63`부터 `2^63−1`까지                                       | `bigint`. 모든 산술 결과에 범위 검사를 수행합니다.                       |
| `실수`    | IEEE 754 binary64 값. 유한값, `+∞`, `−∞`, `NaN`, 부호 있는 0을 포함합니다.                          | JavaScript `number`                                                      |
| `문자열`  | Unicode scalar value 순서열. 비교는 코드 포인트 순서가 아니라 동등 비교만 정의합니다.               | lone surrogate가 없는 JavaScript string                                  |
| `불리언`  | `참` 또는 `거짓`                                                                                    | JavaScript `boolean`                                                     |
| `없음`    | 값이 없음을 나타내는 Unit 타입. 유일한 값은 `없음`입니다. 선택 타입의 빈 값과 다릅니다.             | 비공개 Unit sentinel 또는 `undefined`. 선택 타입 값과 구별되어야 합니다. |
| `목록[T]` | 타입 `T` 값들의 순서 있는 불변 목록                                                                 | 비공개 배열. 외부에 노출하지 않고 변경 불가로 취급합니다.                |
| `사전[T]` | 문자열 키에서 `T` 값으로 가는 불변 사전. 키 비교는 문자열 코드 포인트 순서열의 정확한 동등성입니다. | 비공개 `Map<string, T>` 또는 의미가 같은 표현                            |
| `선택[T]` | `일부(T)` 또는 `비어있음` 중 하나인 태그 합 타입                                                    | 비공개 tag/value 표현. `없음`과 합치면 안 됩니다.                        |

`목록`, `사전`, `선택`의 문법 표기는 `목록[T]`, `사전[T]`, `선택[T]`입니다. `사전`의 키 타입은 v0.1에서 항상 `문자열`이므로 타입 인자는 값 타입 하나입니다. 이 내장 타입은 중첩할 수 있습니다. 매개 타입은 불변(invariant)이며 하위 타입 변환이 없습니다.

JavaScript 표현은 비공개 구현 선택입니다. JavaScript 객체 identity, prototype, 삽입 순서, `undefined`, coercion이 GEULION에서 관찰되면 안 됩니다. 추후 WebAssembly/LLVM 백엔드도 위 추상 의미를 보존해야 합니다.

## 선언과 정적 검사

- `상수`와 `변수`는 항상 초기화 식이 있어야 합니다. 타입 주석이 있으면 초기화 식의 타입과 정확히 일치해야 합니다.
- 타입 주석이 생략된 변수는 초기화 식의 확정된 타입으로 추론합니다. 초기화 식이 `비어있음`, 빈 목록, 빈 사전처럼 문맥 타입을 요구하면 주석이 필요합니다.
- 함수 매개변수와 반환 타입은 반드시 씁니다. 타입이 없는 매개변수, 반환형 추론, 인자 기본값은 없습니다.
- 식에서 bare 함수 이름은 값으로 사용할 수 없습니다. 함수 선언 이름은 `이름(...)` 호출 위치에만 유효하며, 함수 값 타입은 v0.1에 없습니다.
- 타입은 정확히 일치해야 합니다. 정수/실수 승격, truthiness, 문자열/숫자 연결, 자동 unwrapping을 포함해 암시적 변환을 허용하지 않습니다.
- 형식 오류가 있는 식은 `GE3001` 또는 `GE3002`이며 해당 선언/연산의 결과 타입은 오류 타입으로 표시해 연쇄 진단을 억제합니다.
- `변수`만 같은 타입 값으로 재대입할 수 있습니다. `상수` 재대입은 `GE3003`입니다. 컬렉션 원소를 직접 바꾸는 문법은 없습니다.

## 식 타입 추론

| 식                                 | 타입 규칙                                                                                                                         |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 정수 리터럴                        | 값이 `정수` 범위에 있어야 합니다. `2^63` magnitude는 앞에 단항 `-`가 직접 붙은 경우(그룹 괄호는 무시)에만 `−2^63`으로 허용합니다. |
| 실수 리터럴                        | binary64 최근접값(동률은 짝수)으로 변환합니다. 양/음 무한대로 넘치는 리터럴은 `GE3007`입니다.                                     |
| 문자열, `참`, `거짓`, `없음`       | 각각 `문자열`, `불리언`, `없음`입니다.                                                                                            |
| `비어있음`                         | 기대 타입이 `선택[T]`일 때만 `선택[T]`입니다. 다른 문맥은 `GE3006`입니다.                                                         |
| `일부(E)`                          | `E`의 타입이 `T`이면 `선택[T]`입니다. 내부 식은 문맥 타입과 정확히 일치해야 합니다.                                               |
| 비어 있지 않은 목록                | 모든 원소의 타입이 동일한 `T`이면 `목록[T]`입니다. 원소 하나라도 다르면 `GE3001`입니다.                                           |
| 빈 목록 `[]`                       | 기대 타입 `목록[T]`가 있을 때만 그 타입입니다. 없으면 `GE3006`입니다.                                                             |
| 비어 있지 않은 사전                | 값의 타입이 모두 동일한 `T`이면 `사전[T]`입니다. 중복 문자열 키는 `GE3008`입니다.                                                 |
| 빈 사전 `{}`                       | 기대 타입 `사전[T]`가 있을 때만 그 타입입니다. 없으면 `GE3006`입니다.                                                             |
| 변수 이름                          | 선언된 binding의 타입입니다. 선언 초기화 식 안에서는 그 선언의 이름이 아직 보이지 않습니다.                                       |
| 함수 호출                          | 선언된 시그니처의 반환 타입입니다. 인자 수와 각 인자 타입이 정확히 일치해야 합니다.                                               |
| `목록[T][정수]`, `사전[T][문자열]` | 결과는 각각 `선택[T]`입니다.                                                                                                      |
| `선택[T] ?? T`                     | 왼쪽이 빈 값이면 오른쪽을 평가해 반환하고, 일부 값이면 그 payload를 반환합니다. 결과 타입은 `T`입니다.                            |

기대 타입은 변수 주석, 함수 인자/반환 문맥, 컬렉션 원소 문맥에서 검사에 사용됩니다. 단, 숫자 승격이나 일반적인 하위 타입 추론에는 사용하지 않습니다. 기대 타입이 허용하는 유일한 빈 값 문맥은 위의 `비어있음`, `[]`, `{}`입니다.

## 연산자 타입

| 연산자                     | 허용 타입과 결과                                                                                             |
| -------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 단항 `+`, `-`              | `정수 → 정수`, `실수 → 실수`                                                                                 |
| `+`                        | `정수+정수 → 정수`, `실수+실수 → 실수`, `문자열+문자열 → 문자열`                                             |
| `-`, `*`                   | 같은 두 `정수` 또는 같은 두 `실수`; 결과는 피연산자 타입                                                     |
| `/`                        | `정수/정수 → 정수`, `실수/실수 → 실수`                                                                       |
| `%`                        | `정수%정수 → 정수`만 허용                                                                                    |
| `<`, `<=`, `>`, `>=`       | 같은 타입의 `정수` 또는 `실수` 두 개; 결과 `불리언`                                                          |
| `==`, `!=`                 | 같은 타입끼리만 허용. 목록·사전·선택은 구조적 동등 비교를 합니다. 함수는 값이 아니므로 비교 대상이 아닙니다. |
| `그리고`, `또는`, `아니다` | `불리언`만 허용; 결과 `불리언`                                                                               |
| `??`                       | `선택[T]` 왼쪽과 정확히 `T`인 오른쪽; 결과 `T`                                                               |
| `목록[T][index]`           | index는 `정수`; 결과 `선택[T]`                                                                               |
| `사전[T][key]`             | key는 `문자열`; 결과 `선택[T]`                                                                               |

잘못된 피연산자 조합은 `GE3002`입니다. 문자열의 순서 비교, 서로 다른 타입의 비교, 실수 나머지 연산, 목록/사전 연결은 허용하지 않습니다.

## 명시적 변환과 기본 제공 함수

다음 prelude 함수는 예약어가 아니며 고정 시그니처를 가집니다. 이름 해석 단계에서 일반 함수와 같은 규칙으로 찾습니다.

| 함수     | 시그니처         | 의미                                                                                                                                              |
| -------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `정수로` | `(실수) -> 정수` | 유한 binary64 값을 0 방향으로 자릅니다. 변환 전 값이 `−2^63`보다 작거나 `2^63` 이상이면 `GE4003` runtime 진단입니다. `NaN`과 무한대도 거부합니다. |
| `실수로` | `(정수) -> 실수` | binary64 최근접값(동률은 짝수)으로 반올림합니다. 큰 정수는 명시적으로 정밀도가 손실될 수 있습니다.                                                |
| `출력`   | `<T>(T) -> 없음` | v0.1의 모든 타입 값을 표준 출력으로 한 줄 출력합니다. 아래의 의미론 문서에 정한 canonical 표시를 사용합니다.                                      |

`출력<T>`는 언어의 사용자 정의 제네릭 기능이 아니라 단 하나의 내장 다형 함수입니다. 다른 임의 타입 함수는 v0.1에서 다형이 아닙니다. 정수 변환은 수학적 정수 범위 검사를 거쳐야 하고, 단순 JavaScript `Number` 반올림으로 대체할 수 없습니다.
